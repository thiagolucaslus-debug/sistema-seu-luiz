# Módulo WhatsApp Web

O sistema deve oferecer uma tela própria de WhatsApp Web, acessível pelo menu principal, usando a sessão já vinculada no serviço local.

- Configurações continua responsável por conectar e desconectar o aparelho.
- A nova tela mostra conversas, busca, mensagens e quantidade de não lidas.
- Deve permitir iniciar conversa por telefone, enviar texto e enviar arquivo com legenda.
- Mensagens de mídia devem poder ser abertas dentro da conversa.
- Conversas e mensagens devem atualizar automaticamente sem recarregar a tela.
- O módulo deve funcionar nos temas claro e escuro e adaptar-se ao celular.
- Nenhuma mensagem real será enviada durante testes automatizados ou inspeção visual.
